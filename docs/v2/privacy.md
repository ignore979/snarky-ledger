# 隐私（privacy.md）

## 密钥

- DeepSeek key 只写在本机 `.env`，该文件在 `.gitignore` 中，**不进入版本库、不推送到 GitHub**。
- 启动日志不打印密钥；`/api/v2/capabilities` 只返回能力布尔，不返回 key 或内部地址。

## 数据外发

- 调用 DeepSeek 时只发送当前对话上下文，不发送完整账本。
- 图片/语音识别适配器未启用（能力开关关闭），未接入任何外部视觉/语音服务。

## 本机边界

- 服务默认绑定 `127.0.0.1`，`debug=False`。
- 写请求校验 Host 同源；可配 `LEDGER_ACCESS_TOKEN` 加访问令牌。

## 删除

- 账目删除为软删（`deleted_at`），可恢复；清空账本为两步确认，清空后旧请求的 agent 状态被清空。
- 长期记忆只允许白名单类型（分类别名 / 直记偏好 / 月份视图 / 预算偏好），不自动记忆病史、亲友、工资、债务等敏感信息。
